## Hallazgos

- El navegador responde `immutable` solo si el servidor lo dice; Caddy lo pisaba con `no-store` en todas las rutas. Ahora el audio queda fuera de esa regla.
- El Caddyfile duplica la cabecera `Cache-Control` en las respuestas que sí pisa (una de Caddy y otra del origen, con el mismo valor). Es inofensivo y ya ocurría.
- Lighthouse no se ha ejecutado: no hay una instalación disponible aquí. Queda pendiente el criterio «accesibilidad ≥ 95».
