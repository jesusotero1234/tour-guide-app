Tour Guide App — Pipeline de Generación

Flujo completo: desde la petición del usuario hasta la audioguía generada con enriquecimiento RAG

Flujo Principal

  • • POST /generate → validateTourRequest
  • • findExactTour (cache PostgreSQL)
  • • miss → generateFullTour
  • • POI selection via Wikidata + Wikipedia
  • • Seed quality → progressive enrichment

RAG Enrichment

  • • Solo para seeds "thin" (k=3-5)
  • • CityKnowledgeBase → :3002/enrichment/search
  • • Enrichment Server :11435 (MiniLM + turbovec)
  • • Umbral similitud: 0.25
  • • Corpus: 10-15 pasajes pre-indexados por ciudad

Post-procesado

  • • validateSection(): frases prohibidas
  • • Detección registro formal (usted/miren)
  • • Normalización NFD (acentos)
  • • TTS → audio (VoxCPM/Kokoro)
  • • Persistencia en PostgreSQL
