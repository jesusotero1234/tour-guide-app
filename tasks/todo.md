# Madrid narrative pilot v4 checklist

## Evidence boundary

- [ ] Seven V7 scenes preserve exact order, coordinates, distance, and contribution.
- [ ] Every scene has exactly one fact for each explicit V4 role.
- [ ] Atomic Spanish facts contain 8–45 Unicode words and one proposition.
- [ ] Only observable facts contain an on-site cue visible from the observation point.
- [ ] Official source provenance and nested fingerprints validate offline.
- [ ] Fact permutation yields the same plan and every direct fact is assigned once.
- [ ] A synthetic unknown-city case passes through the same generic engine.

## Prose and criticism

- [ ] Code owns all IDs, evidence, relations, transitions, counts, and duration.
- [ ] Writer schema contains only introduction, scene IDs, block kinds, and text.
- [ ] Introduction is 45–75 words; each body is 160–200 Unicode words.
- [ ] Look blocks instruct observation; new names/numbers and repeated seven-grams fail.
- [ ] Walking, observation, and 120 wpm duration produce an accepted 55–65 minutes.
- [ ] Grounding and final verdicts are calculated locally from valid findings/scores.
- [ ] Protocol retry does not consume the one whole-route content repair.
- [ ] Gemma exact digest, full VRAM residency, keep-alive, timeout, and one eviction
  recovery are enforced.

## Madrid qualification and freeze

- [ ] Three fixed variants run sequentially after one Gemma preparation.
- [ ] At least one approval selects by the preregistered deterministic tie-break.
- [ ] Clean re-critique and four valid factual mutation rejections pass.
- [ ] Empty critique metrics and protocol failures cannot count as success.
- [ ] Route, evidence, plan, text, prompts/schemas, models, parameters, variant,
  policies, reports, mutations, preview, and qualification fingerprints are independent.
- [ ] Staged atomic freeze cannot create or overwrite a partial publication.
- [ ] Artifact=`machine_approved`, qualification=`passed`, public tour=`review`,
  pilot=`prepared`; no V4 path emits `published`.
- [ ] Offline CLI validates evidence and replays an existing bundle without network.

## Pilot experience

- [ ] Disabled flag returns 404; missing/invalid fixture shows an explicit error only.
- [ ] Cover, map, seven text scenes, and current stop work on mobile.
- [ ] URL `?stop=N` restores progress; previous/next/end controls are correct.
- [ ] One h1, native buttons, visible focus, 44px targets, `aria-live`, and focus move.
- [ ] Map has an equivalent textual list and current stop is not color-only.
- [ ] Layout passes at 320, 768, 1024, and 1440px with no browser console errors.

## Final verification

- [ ] Backend focused V4 tests and TypeScript pass.
- [ ] Backend full suite introduces no failures beyond the two recorded baseline failures.
- [ ] Route V7, narrative V2, narrative V3, and Madrid V4 offline commands pass.
- [ ] Frontend TypeScript and production build pass.
- [ ] Runtime browser, keyboard, focus, console, network, diff, and secret scans pass.
- [ ] No public preview contains prompts, raw model output, credentials, or private reports.
- [ ] No push or merge; content commit exists only after a passing live freeze.
